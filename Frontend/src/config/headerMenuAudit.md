# Header navigation invariants

- Desktop and mobile render the same primary navigation source.
- Booking uses the shared travel service catalog.
- Every language exposed by the language selector must have human-readable Booking labels.
- Mobile Booking remains complete but compact enough to navigate without an excessively long drawer.
- No menu item should imply a live provider when the service is not live; non-live services open the services hub.
- Menu labels use sentence case and must not be forced to uppercase.
- Header controls must remain usable without overlap from desktop through narrow mobile widths.
