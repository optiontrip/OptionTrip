# Vi world-guide regression matrix

| Area | Must preserve / prove |
| --- | --- |
| Existing flights | Known route triggers real flight tool; no invented price |
| Existing hotels | Known destination triggers real hotel tool; no invented rate |
| Dates | Relative dates resolve against current date; missing dates do not block valid search |
| Memory | Known preferences/trip context are reused |
| Discovery | No-destination emotional/constraint request gets realistic candidates |
| Whole trip | Relevant supporting services considered without service spam |
| Provider readiness | Candidate/missing credentials never become live availability claims |
| Live trip | Safety/disruption/logistics outrank commercial prompts |
| Trip continuity | Supported selections remain attributable to Trip Object |
| Travel Map | Planned/visited/wishlist concepts remain privacy-aware |
| Monetization | Attribution is preserved; commission does not override traveler value |
| Output | Valid JSON and current quick-reply contract preserved |
