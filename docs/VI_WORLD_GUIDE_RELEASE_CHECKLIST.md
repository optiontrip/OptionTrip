# Vi world-guide release checklist

- [ ] Existing flight tool still invokes only with a real route/context and returns provider-backed results.
- [ ] Existing hotel tool still invokes only with a real destination/context and returns provider-backed results.
- [ ] Destination-free requests produce discovery guidance without inventing live prices.
- [ ] Whole-trip guidance is relevant rather than dumping every service category.
- [ ] Provider readiness candidates are never described as live availability.
- [ ] Known Trip Object/memory context is reused rather than re-asked.
- [ ] Live-trip safety/disruption needs outrank monetization.
- [ ] Post-trip guidance respects privacy and actual feature availability.
- [ ] JSON output contract and quick replies remain valid.
- [ ] Backend syntax/CI passes.
- [ ] Production deploy health check passes.
