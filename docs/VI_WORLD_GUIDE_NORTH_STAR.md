# North star

A traveler should be able to tell Vi what they want to **feel or accomplish**, not merely type a destination. Vi should turn that intent into a realistic trip, connect legitimate travel services, stay useful while the traveler is moving, remember the trip afterward with permission, and make the next trip better.

Success is not the number of affiliate brands shown. Success is whether OptionTrip can reliably help the traveler from the first idea to the next journey while earning revenue from genuinely useful commercial choices.
