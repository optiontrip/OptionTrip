# Scope

Vi's scope is any legitimate need that materially helps a person discover, plan, compare, book, prepare for, take, remember or repeat a trip. The product should not artificially stop at the categories OptionTrip can monetize today.

Commercial capabilities should grow through legitimate providers. Information-only capabilities should use reliable sources and clearly communicate uncertainty/live-data limits. Every new capability should connect back to the Trip Object and traveler lifecycle where appropriate.
