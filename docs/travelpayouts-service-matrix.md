# OptionTrip Travelpayouts service matrix

| Traveler need | Prepared providers |
| --- | --- |
| Flights | Aviasales/Travelpayouts, Trip.com, Kiwi.com |
| Stays | Travelpayouts, Trip.com, SuperTravel |
| Rail/bus/ferry | 12Go, Omio, Klook |
| Car rental | QEEQ, EconomyBookings, GetRentacar, AutoEurope |
| Bikes/scooters/motorcycles | BikesBooking |
| Transfers/taxis | GetTransfer, Kiwitaxi, Welcome Pickups, Intui.travel, 12Go, Klook |
| Activities/tours | Tiqets, Klook, WeGoTrip, KKday, Viator, Youtravel, Go City |
| eSIM | Airalo, Drimsim, Saily |
| Insurance | InsuBuy, EKTA |
| Luggage storage | Radical Storage |
| Flight compensation | AirHelp, Compensair |

Prepared means represented in OptionTrip's provider capability architecture. Live availability still requires the exact issued provider configuration.
